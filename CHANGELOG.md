# Changelog

## 0.5.3 — 2026-09-16

- Prepared the first public GitHub alpha source package.
- Restored standard Linux icon-theme lookup (`Icon=aniview`) for Plasma/GNOME launchers.
- Cleaned generated Python cache files from the release source.
- Synchronized release metadata and documentation versions.

Notable changes to AniView are recorded here.

## 0.5.2 — 2026-09-16

### Changed

- Finalized the top search control as a plain text field: type a title and press Enter.
- Removed the search action icon and clear button from the search field.
- Refined public-release documentation and third-party notices.
- Added GitHub issue templates, CI checks, contributing/security guidance, and a release checklist.
- Improved the Fedora installer with platform checks, safer ani-cli fetching, and installed license notices.

### Existing alpha features

- Left navigation with Home, Local Library, and recent anime.
- Continue Watching and popular/trending recommendations.
- Right-click history actions.
- Embedded mpv playback with episode panel and fullscreen controls.
- Local-video folder scanning and playback.

## 0.4.0 — 2026-09-16

- Added left navigation, recommendations, context menus, and Local Library.

## 0.2.0 — 2026-09-15
