# Security Policy

AniView is an early-alpha desktop application.

## Reporting a security problem

If the GitHub repository has **Private vulnerability reporting** enabled, use
GitHub's **Report a vulnerability** option.

If private reporting is not available, open a short issue saying that you have
a security report and avoid posting exploit details, private data, tokens, or
credentials publicly.

## Scope

Useful reports include problems in AniView's own code such as unsafe file
handling, command execution, or exposure of local user data.

Provider outages, broken anime search results, or upstream ani-cli/mpv bugs are
usually not AniView security vulnerabilities unless AniView handles them in an
unsafe way.
